# 🩸 LifeLine — Blood Donor Finder (UX Concept)


**The problem:** In Pakistan, patients in emergencies often wait hours for blood. Families scramble through WhatsApp groups and phone calls while the clock ticks. There is no fast, trusted way to find a verified donor nearby by blood group.


**The solution:** LifeLine is a web concept that connects blood donors with patients instantly — search by blood group and city, contact verified donors directly, and register as a donor in under a minute.


## Demo
Live demo: https://abbasmomand98-jpg.github.io/lifeline-blood-donor-finder/


## ✨ Features
- 🔍 Donor search by blood group + Pakistani city (live filtering)
- 🩸 Donor cards with availability status and privacy-masked phone numbers (tap to reveal)
- 📝 One-minute donor registration with validation and confirmation
- 🆘 Emergency strip with 24/7 helpline
- 📊 Animated impact stats, 3-step "How it works"


## 🛠️ Tech Stack
- HTML5 — semantic markup
- CSS3 — custom properties, responsive grid, no frameworks
- JavaScript — filtering, form validation, animated counters (vanilla, zero dependencies)


## 🚀 Run it
Just open `index.html` in any browser — no build step, no server needed.
